# Primeiros Passos

Este guia mostra o caminho mais rápido para rodar o Kite pela primeira vez.

## Pré-requisitos

| Requisito | Versão mínima |
|---|---|
| Node.js | 18.x |
| npm | 9.x |

## Instalação rápida

```bash
npm install -g kite-cli
kite --version
```

## Primeiro comando

```bash
kite init meu-projeto
cd meu-projeto
kite run
```

:::tip
Use `kite --help` a qualquer momento para ver todos os comandos disponíveis.
:::
