# Instalação

## Via npm

```bash
npm install -g kite-cli
```

## Via script de shell

```bash
curl -sSL https://exemplo.com/install.sh | sh
```

:::warning
Scripts de instalação via `curl | sh` devem ser revisados antes de executar. Este é apenas um exemplo ilustrativo.
:::

## Verificando a instalação

```bash
kite --version
# kite-cli 1.0.0
```
